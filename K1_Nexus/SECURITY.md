# Security Policy

K1 Nexus communicates with a 3D printer over the local network and can issue printer-control commands.

Please do not publish credentials, private keys, Wi-Fi passwords, tokens, or other secrets in issues or logs.

If you discover a security issue, avoid posting exploit details publicly until the maintainer has had a reasonable opportunity to review it. When a private reporting channel is configured for the GitHub repository, use that channel for security reports.
